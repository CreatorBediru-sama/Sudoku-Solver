# Sudoku-Solver
Sudoku solver source code.

First of all, your sudoku need to be in specific form; 

* gaps neet to be represented by zeros (0)
* in between every number, there must be a gap but lines can be arranged one below other.

There is an example sudoku in input_file. And your solvation will be appear on output file
but make sure you just keep all files in one directory and write file paths true on code to
start with visual code.

Also it must be guaranteed that there will be at least one number with only one possibility 
at the each step either by eliminating the possibilities after filling a empty gap or the ones 
that already exist.
